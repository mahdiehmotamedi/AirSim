# بسته راه‌اندازی شبیه‌ساز AirSim/Colosseum — مهدیه معتمدی

این بسته همراه «راهنمای عملی راه‌اندازی شبیه‌ساز AirSim» ساخته شده است و همه چیز لازم برای
رسیدن از صفر تا **ناوبری ۴ پهپاد هم‌زمان + محیط آموزش یادگیری تقویتی چندعاملی** را دارد.

## فهرست فایل‌ها

| فایل | کاربرد | تنظیمات لازم |
|------|--------|--------------|
| `settings.json` | ۴ پهپاد SimpleFlight، اجرای بلادرنگ (برای اسکریپت‌های ۰۱–۰۳) | پیش‌فرض |
| `settings_rl.json` | همان ۴ پهپاد + `SteppableClock` برای گام‌های قطعی RL | برای اسکریپت ۰۴ |
| `settings_lidar.json` | مانند settings.json + لیدار ۱۶ کاناله روی Drone1 | اختیاری |
| `01_test_connection.py` | تست اتصال API و فهرست پهپادها | settings.json |
| `02_multi_drone_demo.py` | برخاست تشکیلی، گشت مربعی، گزارش کمینه فاصله بین‌پهپادی، فرود | settings.json |
| `03_camera_capture.py` | ذخیره RGB + عمق + سگمنتیشن از هر ۴ پهپاد در `captures/` | settings.json |
| `04_marl_gym_env.py` | محیط PettingZoo/Gymnasium برای آموزش MARL (پاداش: پیشرفت − برخورد − فاصله ناایمن) | settings_rl.json |
| `05_guardian_shield.py` | سپر امنیتی GUARDIAN (CBF گرافیکی با اقدام گسسته) + ابزارهای CVaR و تفسیرپذیری + بنچمارک سربار | بدون شبیه‌ساز هم اجرا می‌شود |
| `requirements.txt` | بسته‌های پایتون (پایتون ۳٫۸ تا ۳٫۱۰) | — |
| `setup_ubuntu.sh` | ساخت UE 5.3 + Colosseum روی اوبونتو ۲۰٫۰۴ | — |

## ترتیب اجرا

```bash
# ۰) شبیه‌ساز را اجرا کنید (CityEnviron.exe یا BlocksV2)
#    و settings.json را در Documents/Colosseum/ گذاشته باشید

# ۱) محیط پایتون
python -m venv .venv && .venv\Scripts\activate     # ویندوز
pip install -r requirements.txt

# ۲) تست اتصال
python 01_test_connection.py

# ۳) پرواز گروهی
python 02_multi_drone_demo.py

# ۴) گرفتن تصویر
python 03_camera_capture.py

# ۵) محیط RL (ابتدا settings_rl.json را جای settings.json بگذارید و شبیه‌ساز را ری‌استارت کنید)
python 04_marl_gym_env.py          # تست خودمختار با سیاست تصادفی

# ۶) سپر امنیتی GUARDIAN — تست و بنچمارک بدون شبیه‌ساز (فقط numpy لازم است)
python 05_guardian_shield.py       # تست عملکردی + جدول میلی‌ثانیه بر گام
```

## مسیر فایل تنظیمات (خیلی مهم!)

| پلتفرم | Colosseum (توصیه‌شده) | AirSim اصلی |
|--------|----------------------|-------------|
| ویندوز | `%USERPROFILE%\Documents\Colosseum\settings.json` | `Documents\AirSim\settings.json` |
| لینوکس | `~/Documents/Colosseum/settings.json` | `~/Documents/AirSim/settings.json` |

اگر اسکریپت‌ها «API not responding» دادند، ۹۹٪ یعنی settings.json در مسیر درست نیست
یا شبیه‌ساز هنوز Play نخورده است.

## یادداشت برای رساله

- سنجه‌ی «کمینه فاصله بین‌پهپادی» که فرضیه ۱ (ایمنی) رساله لازم دارد، هم در
  `02_multi_drone_demo.py` و هم داخل محیط RL (متغیر `min_separation` در `infos`) محاسبه می‌شود.
- شکل‌دهی پاداش در `AirSimMultiUAVEnv._compute_reward` صراحتاً با سه فرضیه رساله
  برچسب‌گذاری شده تا در فصل آزمایش‌ها مستقیم به آن استناد کنید.
- استرس‌سازهای محیط پویا: `set_wind(...)` و `set_weather("Rain", 0.6)` برای سناریوهای باد و باران.

## سپر امنیتی GUARDIAN (منطبق با مقاله ژورنالی)

فایل `05_guardian_shield.py` همان فیلتر سپردار مقاله است و مستقیم قابل استناد در فصل آزمایش‌ها:

- **معادلات ۶ تا ۸ مقاله**: حاشیه مانع `h_j`، شرط گسسته CBF و انتخاب اقدام ایمن با بازگشت
  `brake-and-climb` — دقیقاً با همان پارامترها (`delta=0.5m`، `gamma_s=0.35`، مجموعه اقدام گسسته K=11).
- **ابزارهای ریسک/تفسیرپذیری**: اتلاف هابر کوانتایلی (معادله ۹)، CVaR از کوانتایل‌ها (معادله ۱۰)،
  ارزش ترکیبی (معادله ۱۱) و همبستگی اسپیرمن توجه/حاشیه (معادله ۱۴).
- **اتصال به محیط RL**: کافی است بعد از ساخت محیط، `env.attach_guardian_shield()` را صدا بزنید؛
  از آن پس هر اقدام سیاست پیش از ارسال به AirSim گواهی‌گیری و در صورت نیاز تصویر می‌شود.
- **تولید اعداد جدول ۷ مقاله**: خروجی `python 05_guardian_shield.py` جدول «میلی‌ثانیه بر گام»
  را برای ۶/۸/۱۲/۲۰/۳۰ عامل در دو رژیم «متراکم» و «شهری» (با شش مانع متحرک) چاپ می‌کند.
  اعداد جدول ۷ در نسخهٔ فعلی مقاله، خروجی اندازه‌گیری‌شدهٔ همین بنچمارک روی یک CPU دو هسته‌ای
  x86-64 است (لاگ کامل: `benchmark_results.txt`)؛ اگر روی سخت‌افزار دیگری اجرا می‌کنید،
  خروجی همان اسکریپت را جایگزین کنید و مشخصات سخت‌افزار را در بخش پیاده‌سازی ذکر کنید.
- یادداشت نسخه: سایر اعداد نتایج (جدول‌های ۵ و ۶ و بخش‌هایی از جدول ۷ و شکل‌های ۳ تا ۶) نمونه‌اند
  و باید با خروجی واقعی آموزش و ارزیابی روی AirSim جایگزین شوند؛ سایر بخش‌های مقاله نهایی است.
